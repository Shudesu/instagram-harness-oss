# @line-harness/sdk v0.1 Design Spec

## Purpose

Typed HTTP client SDK for LINE Harness Worker API. Enables Claude Code (and other AI agents) to fully automate LINE official account operations — scenario delivery, friend management, broadcasts — via natural language → SDK calls.

Replaces L社/U社's manual GUI operations with programmatic AI-driven control.

## v0.1 Scope (Round 1-2 features only)

### Included
- Friends (list with pagination, get, count, tag assignment)
- Tags (create, list, delete — no update endpoint exists)
- Scenarios (CRUD, step management, enrollment)
- Broadcasts (CRUD, schedule, send)
- High-level convenience methods for common workflows

### Excluded (Round 3 — future versions)
- Webhooks IN/OUT
- Calendar/Reminders
- Scoring
- Templates
- Operator chat
- Notifications
- Stripe
- BAN detection
- Automations (IF-THEN)
- Auto-replies (DB exists but no API route yet)

## API Design

### Initialization

```ts
import { LineHarness } from '@line-harness/sdk'

const client = new LineHarness({
  apiUrl: 'https://line-crm-worker.line-crm-api.workers.dev',
  apiKey: 'your-api-key',
})
```

### Low-Level API (1:1 with Worker endpoints)

#### Friends

```ts
// List friends (paginated, optional tag filter)
const result = await client.friends.list({ limit: 50, offset: 0, tagId: 'optional-tag-id' })
// result → { items: Friend[], total, page, limit, hasNextPage }

// Get single friend (includes tags)
const friend = await client.friends.get(friendId)

// Get total friend count
const count = await client.friends.count()

// Add tag to friend
await client.friends.addTag(friendId, tagId)

// Remove tag from friend
await client.friends.removeTag(friendId, tagId)
```

#### Tags

```ts
// Create tag
const tag = await client.tags.create({ name: 'VIP', color: '#EF4444' })

// List all tags
const tags = await client.tags.list()

// Delete tag
await client.tags.delete(tagId)

// Note: no update endpoint exists in the Worker API
```

#### Scenarios

```ts
// List all scenarios (includes stepCount)
const scenarios = await client.scenarios.list()

// Create scenario
const scenario = await client.scenarios.create({
  name: '教育ステップ配信',
  triggerType: 'friend_add',
})

// Add steps
await client.scenarios.addStep(scenario.id, {
  stepOrder: 1,
  delayMinutes: 0,
  messageType: 'text',
  messageContent: 'ようこそ！LINE Harnessへ',
})

await client.scenarios.addStep(scenario.id, {
  stepOrder: 2,
  delayMinutes: 1440, // 1 day
  messageType: 'text',
  messageContent: '3つの強みをご紹介',
})

// Get scenario with steps
const full = await client.scenarios.get(scenarioId)

// Update scenario
await client.scenarios.update(scenarioId, { isActive: false })

// Manually enroll a friend
await client.scenarios.enroll(scenarioId, friendId)

// Update a step
await client.scenarios.updateStep(scenarioId, stepId, {
  messageContent: 'Updated message',
})

// Delete a step
await client.scenarios.deleteStep(scenarioId, stepId)

// Delete scenario
await client.scenarios.delete(scenarioId)
```

#### Broadcasts

```ts
// Create draft
const broadcast = await client.broadcasts.create({
  title: '週末セール告知',
  messageType: 'text',
  messageContent: '今週末限定50%OFF！',
  targetType: 'all',
})

// Schedule (setting scheduledAt automatically changes status to 'scheduled')
await client.broadcasts.update(broadcastId, {
  scheduledAt: '2026-03-25T09:00:00Z',
})

// Unschedule (setting scheduledAt to null reverts status to 'draft')
await client.broadcasts.update(broadcastId, {
  scheduledAt: null,
})

// Send immediately
await client.broadcasts.send(broadcastId)

// List all
const broadcasts = await client.broadcasts.list()

// Get single
const broadcast = await client.broadcasts.get(broadcastId)

// Delete
await client.broadcasts.delete(broadcastId)
```

### High-Level API (Convenience Workflows)

```ts
// Create a complete step scenario in one call
const scenario = await client.createStepScenario('教育ステップ', 'friend_add', [
  { delay: '0m', type: 'text', content: 'ようこそ！' },
  { delay: '1d', type: 'text', content: '3つの強みをご紹介します。' },
  { delay: '3d', type: 'flex', content: flexMessageJson },
])

// Broadcast text to all friends
await client.broadcastText('今週末セール！50%OFF')

// Broadcast to tagged friends
await client.broadcastToTag(tagId, 'text', 'VIP限定クーポン：CODE123')
```

## Types

```ts
// ─── Config ─────────────────────────────────────────────

interface LineHarnessConfig {
  apiUrl: string
  apiKey: string
  timeout?: number  // default: 30000ms
}

// ─── API Response ───────────────────────────────────────

interface ApiResponse<T> {
  success: boolean
  data: T
  error?: string
}

interface PaginatedData<T> {
  items: T[]
  total: number
  page: number
  limit: number
  hasNextPage: boolean
}

// ─── Common ─────────────────────────────────────────────

type ScenarioTriggerType = 'friend_add' | 'tag_added' | 'manual'
type MessageType = 'text' | 'image' | 'flex'
type BroadcastStatus = 'draft' | 'scheduled' | 'sending' | 'sent'

// ─── Friend ─────────────────────────────────────────────

interface Friend {
  id: string
  lineUserId: string
  displayName: string | null
  pictureUrl: string | null
  statusMessage: string | null
  isFollowing: boolean
  tags: Tag[]
  createdAt: string
  updatedAt: string
}

interface FriendListParams {
  limit?: number   // default: 50
  offset?: number  // default: 0
  tagId?: string   // filter by tag
}

// ─── Tag ────────────────────────────────────────────────

interface Tag {
  id: string
  name: string
  color: string
  createdAt: string
}

interface CreateTagInput {
  name: string
  color?: string  // default: '#3B82F6'
}

// ─── Scenario ───────────────────────────────────────────

interface Scenario {
  id: string
  name: string
  description: string | null
  triggerType: ScenarioTriggerType
  triggerTagId: string | null
  isActive: boolean
  createdAt: string
  updatedAt: string
}

interface ScenarioListItem extends Scenario {
  stepCount: number
}

interface ScenarioWithSteps extends Scenario {
  steps: ScenarioStep[]
}

interface ScenarioStep {
  id: string
  scenarioId: string
  stepOrder: number
  delayMinutes: number
  messageType: MessageType
  messageContent: string
  createdAt: string
}

interface CreateScenarioInput {
  name: string
  description?: string
  triggerType: ScenarioTriggerType
  triggerTagId?: string
  isActive?: boolean
}

interface CreateStepInput {
  stepOrder: number
  delayMinutes: number
  messageType: MessageType
  messageContent: string
}

interface UpdateScenarioInput {
  name?: string
  description?: string | null
  triggerType?: ScenarioTriggerType
  triggerTagId?: string | null
  isActive?: boolean
}

interface UpdateStepInput {
  stepOrder?: number
  delayMinutes?: number
  messageType?: MessageType
  messageContent?: string
}

interface FriendScenarioEnrollment {
  id: string
  friendId: string
  scenarioId: string
  currentStepOrder: number
  status: 'active' | 'paused' | 'completed'
  startedAt: string
  nextDeliveryAt: string | null
  updatedAt: string
}

// ─── Broadcast ──────────────────────────────────────────

interface Broadcast {
  id: string
  title: string
  messageType: MessageType
  messageContent: string
  targetType: 'all' | 'tag'
  targetTagId: string | null
  status: BroadcastStatus
  scheduledAt: string | null
  sentAt: string | null
  totalCount: number
  successCount: number
  createdAt: string
}

interface CreateBroadcastInput {
  title: string
  messageType: MessageType
  messageContent: string
  targetType: 'all' | 'tag'
  targetTagId?: string
  scheduledAt?: string
}

  title?: string
  messageType?: MessageType
  messageContent?: string
  targetType?: 'all' | 'tag'
  targetTagId?: string | null

}

// ─── High-Level ─────────────────────────────────────────

// Human-readable delay: '0m', '30m', '1h', '2h', '1d', '3d', '1w'
```

## Error Handling

```ts
import { LineHarness, LineHarnessError } from '@line-harness/sdk'

try {
  await client.scenarios.get('nonexistent-id')
} catch (err) {
  if (err instanceof LineHarnessError) {
    err.status    // HTTP status code (e.g. 404)
    err.message   // Error message from API (e.g. 'Scenario not found')
    err.endpoint  // The endpoint that failed (e.g. 'GET /api/scenarios/xxx')
  }
}
```

`LineHarnessError` is thrown for API errors (4xx, 5xx). Network errors (DNS, timeout) propagate as native `TypeError` from fetch.

## Delay String Parsing

High-level API accepts human-readable delay strings:

| Input | Minutes |
|-------|---------|
| `'0m'` | 0 |
| `'30m'` | 30 |
| `'1h'` | 60 |
| `'2h'` | 120 |
| `'1d'` | 1440 |
| `'3d'` | 4320 |
| `'1w'` | 10080 |

Invalid format throws `Error('Invalid delay format: ...')`.

## Build & Publish

- TypeScript → ESM + CJS dual output
- `tsup` for bundling
- Types exported via `exports` field
- Target: Node 18+ (for native fetch)
- Zero dependencies (uses native fetch)

```json
{
  "name": "@line-harness/sdk",
  "version": "0.1.0",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.cjs",
      "types": "./dist/index.d.ts"
    }
  }
}
```

## Testing Strategy

- Unit tests for delay parsing, type serialization
- Integration tests against a local Worker (miniflare)
- No mocks for HTTP — test against real API shape

## Non-Goals for v0.1

- CLI tool (`@line-harness/cli`)
- Worker deployment/scaffolding
- Admin UI
- Direct LINE API calls (that's what `@line-crm/line-sdk` does)
- Webhook receiving
- Round 3 features
- Auto-replies (DB exists but no API route)
